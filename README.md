# 東方天盗梨子 配布ページ

サークル「無名地帯」の落ちものパズル×東方ゲーム **東方天盗梨子** シリーズの、本体の配布・自動更新用リポジトリです。

## ダウンロード

[Releases](../../releases/latest) から最新の `*.exe`(インストーラー)をダウンロードしてください。Windows 専用です。
一度インストールすれば、以降の更新はゲームが自動で行います。

## 遊び方

1. インストーラーを実行して、ゲームを起動します。
2. 遊びたい作品を選びます。最初は鍵がかかっています。
3. 「🔑 解放鍵を登録」から、購入した **解放鍵ファイル(`.key`)** を選ぶと、その作品が遊べるようになります。
   - 解放鍵は作品ごとに Booth で配布しています。
   - 一度登録すれば、次回からは不要です。

## 注意

- 署名のない実行ファイルのため、初回は Windows SmartScreen の警告が出ることがあります。「詳細情報」→「実行」で起動できます。
- 本体は無料ですが、作品を遊ぶには解放鍵が必要です。
- 体験版(第1作プロローグのみ)は別途配布しています。
